# PSL Ascension: Плеер Луксмаксинга (Пресет из 16 реальных MP3-треков)

Обновление музыкального модуля игры на главной странице: переход на **настоящий потоковый MP3-аудиоплеер (`HTMLAudioElement`)** с готовым фиксированным пресетом из **16 студийных треков** в эстетике луксмаксинга (Drift Phonk, Dark Synthwave, Krushclub, Midtempo Bass, Gym Hardstyle) без лишних кнопок загрузки файлов пользователем.

---

## Подтвержденные решения

> [!IMPORTANT]
> **Фиксированный пресет из 16 реальных MP3-композиций (Без загрузки файлов игроком)**
> 1. **Только готовый плейлист (16 треков)**: Никаких диалогов выбора файлов или пользовательских загрузок — в плеер сразу встроены 16 реальных полноформатных MP3-композиций с прямой потоковой подгрузкой, которые идеально ложатся под мьюинг, бонсмэшинг и эдиты с Chico Lachowski / Jordan Barrett.
> 2. **Настоящий эффект Slowed (Pitch + Tempo)**: При включении тумблера `Slowed 0.84x` плеер замедляет реальный MP3-поток с понижением тональности (`audio.preservesPitch = false`), создавая аутентичное звучание TikTok-эдитов по луксмаксингу.
> 3. **Полноценное управление аудио**: Полоса перемотки трека с таймером (`01:15 / 02:48`), ползунок громкости (`0%–100%`), переключение `Пред. / Играть / След.`, автоматический переход к следующему треку по окончании и авто-пауза при показе рекламы `YaGames SDK v2`.

## 2. Пользовательский опыт и интерфейс плеера

1. **Блок текущего трека и перемотки**:
   - Название активного трека, поджанр, индикатор времени (`текущее / длительность`) и интерактивный ползунок перемотки (seek bar).
   - Кнопки `Пред.`, `Играть / Пауза`, `След.` и переключатель `Slowed 0.84x` / `Original 1.0x`.
2. **Регулятор громкости**:
   - Плавный ползунок громкости от `0%` до `100%` с мгновенным откликом `HTMLAudioElement.volume`.
3. **Прокручиваемый список из 16 треков**:
   - Компактный список на главной странице слева (вместо старой шкалы PSL), позволяющий в 1 клик включить любую из 16 композиций.
